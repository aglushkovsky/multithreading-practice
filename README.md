Создать следящий поток, который при появлении информации из входных фаилов в хранилище будет записывать в фаил с именем фаила входного + постфикс -output (например входной фаил input.txt, а выходной будет input-output.txt) (хранилище должно разделять набор записей по каждому из фаилов)
